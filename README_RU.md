# Дорожная карта — прототип Android

Это стартовый прототип приложения Android с WebView и картой OpenStreetMap.

## Что есть сейчас
- карта OpenStreetMap;
- запрос геолокации;
- форма с комментарием и выбором фотографии;
- добавление локальной отметки;
- тестовые подтверждения/опровержения;
- отметки старше двух часов скрываются в этом прототипе.

## Чего пока нет
- регистрации и входа;
- передачи фото на сервер;
- общей базы для разных пользователей;
- проверки достоверности фото и времени съёмки;
- push-уведомлений;
- безопасной серверной авторизации.

Все отметки локальные и демонстрационные. Не используйте прототип для принятия дорожных решений. Данные OpenStreetMap загружаются через интернет.

## Как получить APK без компьютера
1. Создайте аккаунт GitHub и войдите в него в браузере телефона.
2. Создайте новый пустой репозиторий, например `dorozhnaya-karta`.
3. Загрузите содержимое этого архива в репозиторий так, чтобы файл `.github/workflows/build-apk.yml` сохранил свой путь.
4. Откройте вкладку **Actions** в репозитории.
5. Выберите **Build Android APK** и нажмите **Run workflow** (или дождитесь автоматической сборки после загрузки файлов).
6. Когда запуск станет зелёным, откройте его и в разделе **Artifacts** скачайте `DorozhnayaKarta-debug-apk`.
7. Распакуйте скачанный ZIP на телефоне. Внутри будет `app-debug.apk`. Откройте APK и, если Android попросит, разрешите установку из этого источника.

GitHub Actions выполняет сборку в облаке; компьютер пользователя не нужен. Для частного репозитория и использования Actions действуют лимиты и условия GitHub.

## Важно про первую сборку
Это непроверенный в текущей среде стартовый проект; облачная сборка может выявить несовместимость конфигурации, которую потребуется исправить. Установка debug APK подходит для тестирования, не для публикации в Google Play.

## Примечания
- Ключевые данные в реальном приложении нужно хранить на сервере с правилами доступа.
- Потребуются политика конфиденциальности, модерация и соблюдение местных законов.
- Используйте тайлы OpenStreetMap в соответствии с политикой их использования; для большого числа пользователей может понадобиться другой поставщик тайлов.
